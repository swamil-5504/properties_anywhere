# PropertiesAnywhere – Frontend

PropertiesAnywhere is a Flutter-based property rental application inspired by platforms like WG-Gesucht.

Users will be able to search for properties, view listings, and create their own rental listings.

## Tech Stack

- Flutter
- Dart
- Android

## Current Features

- Search properties by city
- Display property details
- Display property images
- Create property listings
- Connect with Spring Boot backend
